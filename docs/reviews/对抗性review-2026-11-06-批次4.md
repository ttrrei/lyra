## 关键修正细节（A1 重点）

A1 是本批次**价值最高**的一条。原始实现：

```python
# ❌ 修复前：base64(24) 与 hex(32) 直接字符串比较 → 恒 False → 恒重下
def _md5_matches(local, remote_md5):
    ...
    return _md5_of_file(local) == str(remote_md5).lower()
```

因为 PAR **列表**接口返回 base64、**下载**接口的 Etag 返回 hex，两者对同一
文件编码不同，直接比较**永远不相等**，于是"md5 命中跳过"这条路径**从一
开始就不可达**——I20 实际退化成"size 回退"，而 size 回退在内容同长时又
会误判为最新。moneta 的 `extract_oci.py` 正是因为这个坑只做了 size 比较。

修复后（`oci_client.py`）：

```python
# ✅ 修复后：归一化到 hex 再比较
def _to_md5_hex(remote_md5: str) -> str | None:
    v = remote_md5.strip().strip('"')
    if len(v) == 32 and all(c in "0123456789abcdefABCDEF" for c in v):
        return v.lower()                      # 已是 hex
    if len(v) in (24, 25):                    # base64 → 16 字节 digest
        digest = base64.b64decode(v + "=" * (-len(v) % 4))
        if len(digest) == 16:
            return digest.hex()
    return None
```

并补了**纯函数级**验证（`_md5_matches` 对 base64 形、hex 形、错值、None
四例）+ **集成级**验证（`test_oci_download_md5_mismatch`：本地 md5 不符必
重下且结果为新字节；本地相符必跳过且**只多一次 list 请求**）。
